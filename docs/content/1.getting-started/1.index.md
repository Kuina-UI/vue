## What is Kuina UI?

Kuina UI is a Vue component library styled with [Tailwind CSS](https://tailwindcss.com/). It brings the Kuina design to your Nuxt and Vue apps, installed from npm.

## Core technologies

Every component is written for Kuina, with no headless component library underneath. Tailwind CSS handles the styling.

### Accessibility

Interactive components follow the [WAI-ARIA authoring practices](https://www.w3.org/WAI/ARIA/apg/):

- **Semantic HTML**: native elements first, ARIA roles only where HTML has none
- **Keyboard support**: every interactive component works without a mouse
- **Visible focus**: a focus ring on every control

### Tailwind CSS

Kuina UI is styled with [Tailwind CSS v4](https://tailwindcss.com/):

- **Design tokens as theme variables**: Kuina colors and spacing are Tailwind theme variables, so the classes you write in your app use the same tokens as the components
- **CSS-first configuration**: import Kuina UI in your CSS file, no JavaScript config
- **Light and dark variants**: `light:` and `dark:` follow the `data-theme` attribute on `<html>`, not the OS setting

## Key features

### Nuxt and Vue

::framework-only
#nuxt
- **Nuxt module**: one line in `nuxt.config.ts` registers every component, ready to use without imports
- **Server-side rendering**: components render on the server and hydrate without mismatches

#vue
- **Named imports**: import only the components you use, `import { KButton } from '@kuina-ui/vue'`
- **Any Vue 3 project**: works with Vite, Laravel, Astro and any setup that runs Vue 3.5+
::

::tip{to="/getting-started/installation"}
Use the **Nuxt / Vue** switch in the header to show the guide for your framework.
::

### TypeScript support

Components are written in TypeScript, so props and events come with auto-completion and type checking in your editor.

## FAQ

::accordion

:::accordion-item{label="Is Kuina UI free to use?"}
Yes. Kuina UI is free and open source under the MIT license.
:::

:::accordion-item{label="Can I use Kuina UI without Nuxt?"}
Yes. Kuina UI works in any Vue 3.5+ project. Switch to **Vue** in the header and follow the [installation guide](/getting-started/installation).
:::

:::accordion-item{label="Do I need Tailwind CSS?"}
Yes. Kuina UI is styled with Tailwind CSS v4, which your project needs to compile the component classes and the Kuina tokens.
:::

:::accordion-item{label="Where can I get help?"}
Ask questions or report bugs on [GitHub](https://github.com/Kuina-UI/vue/issues).
:::
