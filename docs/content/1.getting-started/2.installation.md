## Requirements

::framework-only
#nuxt
- Nuxt 4
- Tailwind CSS v4

#vue
- Vue 3.5 or later
- Tailwind CSS v4
::

## Setup

::framework-only
#nuxt
:::steps{level="4"}

#### Install Kuina UI and Tailwind CSS

::::code-group{sync="pm"}

```bash [npm]
npm install @kuina-ui/vue tailwindcss
```

```bash [pnpm]
pnpm add @kuina-ui/vue tailwindcss
```

```bash [yarn]
yarn add @kuina-ui/vue tailwindcss
```

```bash [bun]
bun add @kuina-ui/vue tailwindcss
```

::::

#### Add the Kuina UI module to `nuxt.config.ts`

```ts [nuxt.config.ts]
export default defineNuxtConfig({
  modules: ['@kuina-ui/vue/nuxt']
})
```

#### Import Tailwind CSS and Kuina UI in `main.css`

::::code-group

```css [app/assets/css/main.css]
@import "tailwindcss";
@import "@kuina-ui/vue";
```

```ts [nuxt.config.ts] {3}
export default defineNuxtConfig({
  modules: ['@kuina-ui/vue/nuxt'],
  css: ['~/assets/css/main.css']
})
```

::::

#### Set the theme in `app.vue`

```vue [app/app.vue]
<script setup lang="ts">
useHead({
  htmlAttrs: { 'data-theme': 'light' }
})
</script>

<template>
  <NuxtPage />
</template>
```

#### Use a component, no import needed

```vue [app/pages/index.vue]
<template>
  <KButton>Save</KButton>
</template>
```

:::

#vue
:::steps{level="4"}

#### Install Kuina UI, Tailwind CSS and its Vite plugin

::::code-group{sync="pm"}

```bash [npm]
npm install @kuina-ui/vue tailwindcss @tailwindcss/vite
```

```bash [pnpm]
pnpm add @kuina-ui/vue tailwindcss @tailwindcss/vite
```

```bash [yarn]
yarn add @kuina-ui/vue tailwindcss @tailwindcss/vite
```

```bash [bun]
bun add @kuina-ui/vue tailwindcss @tailwindcss/vite
```

::::

#### Add the Tailwind CSS plugin to `vite.config.ts`

```ts [vite.config.ts] {3,6}
import { defineConfig } from 'vite'
import vue from '@vitejs/plugin-vue'
import tailwindcss from '@tailwindcss/vite'

export default defineConfig({
  plugins: [vue(), tailwindcss()]
})
```

#### Import Tailwind CSS and Kuina UI in your stylesheet

::::code-group

```css [src/assets/main.css]
@import "tailwindcss";
@import "@kuina-ui/vue";
```

```ts [src/main.ts] {1}
import './assets/main.css'
import { createApp } from 'vue'
import App from './App.vue'

createApp(App).mount('#app')
```

::::

#### Set the theme in `index.html`

```html [index.html]
<html lang="en" data-theme="light">
```

#### Import and use a component

```vue [src/App.vue]
<script setup lang="ts">
import { KButton } from '@kuina-ui/vue'
</script>

<template>
  <KButton>Save</KButton>
</template>
```

:::
::

## Themes

Kuina UI comes in a light and a dark theme. The `data-theme` attribute on `<html>` picks it: set it to `light` or `dark`, and every component follows, along with the `light:` and `dark:` variants in your own classes.
